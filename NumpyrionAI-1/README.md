Currently, this AI is very small( if you go by parameter count it is 125M) but it has no fixed parameter count.

To use this you need to download requirements.txt then use the command :  pip install -r requirements.txt
Then you need to download all  python files( AI_functions.py, Custom_Embedder.py, numpyrion.py) as the AI(numpyrion.py) depends upon the other 2 files.
Make sure that all these files are in the same folder.
And just go to that folder in your terminal and run it! (command to run it: python numpyrion.py)
